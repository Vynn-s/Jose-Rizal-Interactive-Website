
  # Interactive Timeline Website Design

  This is a code bundle for Interactive Timeline Website Design. The original project is available at https://www.figma.com/design/FE2QNlZX7QSf90kmKsmIwZ/Interactive-Timeline-Website-Design.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Deploying to Vercel

  This project is a standard Vite app, so it can be deployed to Vercel without extra routing configuration.

  Use `pnpm build` for the production build command and keep the output directory as `dist`.

  If Vercel prompts for framework detection, select Vite.
